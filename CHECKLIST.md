## Manual setup (human does these in Google — skill cannot)

- [ ] **Google Analytics** — create a GA4 property, then paste the
      Measurement ID (`G-…`) into `lib/analytics.ts` (or set
      `NEXT_PUBLIC_GA_MEASUREMENT_ID` in the hosting dashboard).
- [ ] **Google Tag Manager** — create a container, then paste the ID
      (`GTM-…`) into `lib/analytics.ts` (or set `NEXT_PUBLIC_GTM_CONTAINER_ID`).
      If GTM will also fire a GA tag, use only one of the two to avoid
      counting visits twice.
- [ ] **Google Search Console** — verify vote4aaron.com (DNS is easiest),
      then submit `https://vote4aaron.com/sitemap.xml`.

  consent check. Only paste IDs into `lib/analytics.ts`.

  and `public/llms.txt`.
